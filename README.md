# Shri Shirva Bhanushali Mahajan

A refined community platform celebrating heritage, service, and collective progress for the Shirva village Bhanushali community.

## About

**Shri Shirva Bhanushali Mahajan** is a premium community organization dedicated to:

- **Service** - Supporting community members and charitable causes
- **Heritage** - Preserving and celebrating cultural traditions
- **Education** - Promoting learning and development opportunities
- **Collective Welfare** - Fostering unity and mutual support

## Features

- **Modern, responsive design** - Beautiful interface that works on all devices
- **Community information** - Detailed sections about the organization and initiatives
- **Professional styling** - Premium appearance with elegant color scheme
- **Accessible** - Keyboard navigation and accessibility support

## Design

The website features:
- **Color Scheme**: Maroon (#7a1f2b), Saffron (#d97706), Gold (#c8a24a)
- **Typography**: Playfair Display (headings) and Poppins (body text)
- **Layout**: Responsive container-based design
- **Effects**: Smooth scrolling, subtle shadows, and elegant transitions
